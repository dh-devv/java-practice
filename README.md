# java-practice

자바의 기초 개념을 학습 순서에 따라 정리하고, 각 개념을 확인할 수 있는 예제 코드를 함께 관리하는 저장소입니다.

## 학습 순서

각 주제 폴더를 번호 순서로 살펴보세요. 자세한 설명과 예제는 각 폴더 안에서 확인할 수 있습니다.

## 폴더 구조

- [basic](basic/) 
- [array](array/)
- [control_flow](control_flow/)
- [method](method/)
- [oop](oop/)
- [mini_project](mini_project/)

## 문서와 예제 코드

설명 문서와 관련 Java 예제는 같은 주제 폴더에 둡니다. 개념 문서는 핵심 설명과 예제를 중심으로 읽고, 예제 코드를 실행해 설명한 결과를 확인합니다. 새 주제를 추가할 때는 기존 순서에 맞춰 번호가 붙은 하위 폴더를 만듭니다.

## 실행 환경

예제는 Visual Studio Code에서 작성하고 실행합니다. 자바 파일을 컴파일하면 생기는 `.class` 파일은 저장소의 `.gitignore` 규칙에 따라 Git에서 제외됩니다.
