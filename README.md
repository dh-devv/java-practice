# java-practice

자바 기초 문법과 프로그래밍 개념을 익히기 위한 학습 저장소입니다. 번호가 붙은 폴더로 학습 순서를 정리하고, 각 주제의 설명과 예제 코드를 모읍니다.

## 폴더 구성

| 폴더 | 내용 |
| --- | --- |
| `basics/` | 자바 소개, 기본 구조, 첫 프로그램, 변수와 자료형 등 기초 문법 |
| `array/` | 배열의 선언과 사용 |
| `control_flow/` | 조건문과 반복문 등 실행 흐름 제어 |
| `method/` | 메서드의 선언, 매개변수, 반환값과 호출 |
| `oop/` | 클래스와 객체를 비롯한 객체 지향 프로그래밍 |
| `mini_project/` | 배운 내용을 활용하는 작은 프로젝트 |

각 주제 폴더 안에서는 학습 순서에 따라 `01_...`, `02_...`처럼 번호가 붙은 폴더를 만들고, 관련 설명 파일과 자바 코드를 그 안에 넣습니다.

예를 들어 `basics/`는 다음과 같이 정리합니다.

```text
basics/
├── 01_basic/      # 자바 소개와 기본 구조
├── 02_hello/      # 첫 번째 자바 프로그램
└── 03_variable/  # 변수와 자료형
```

자바 예제는 VS Code에서 열어 실행합니다. 컴파일 결과인 `.class` 파일은 `.gitignore` 규칙으로 Git 추적 대상에서 제외됩니다.
