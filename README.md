# java-practice

자바를 공부하며 개념 설명과 예제 코드를 주제별로 정리하는 저장소입니다. 예제 작성과 실행은 Visual Studio Code에서 진행합니다.

## 큰 주제 폴더

| 폴더 | 학습 내용 |
| --- | --- |
| `basics/` | 자바의 기본 구조, 자료형, 연산자, 문자열 등 기초 문법 |
| `array/` | 배열의 선언, 값 저장, 반복 처리 *(학습 예정)* |
| `control_flow/` | 조건문과 반복문을 이용한 실행 흐름 제어 *(학습 예정)* |
| `method/` | 메서드의 선언, 매개변수, 반환값과 호출 *(학습 예정)* |
| `oop/` | 클래스와 객체, 상속 등 객체 지향 프로그래밍 *(학습 예정)* |
| `mini_project/` | 배운 내용을 활용하는 작은 프로젝트 *(학습 예정)* |

## 학습 내용 정리

각 큰 주제 폴더 안에 `01_주제`, `02_주제`처럼 번호를 붙인 하위 폴더를 만들어 학습 순서를 표시합니다. 설명 문서와 자바 예제는 해당 주제 폴더에 함께 넣습니다. 새 내용을 추가할 때도 다음 번호의 폴더를 만들면 됩니다. 예를 들어 `basics/01_basic/`, `basics/02_hello/`처럼 정리합니다.

VS Code에서 자바 파일을 열어 실행합니다. 컴파일 결과인 `.class` 파일은 `.gitignore` 규칙에 따라 Git에서 제외됩니다.
