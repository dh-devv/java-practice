# 자바 파일과 프로그램의 기본 구조

자바 프로그램은 클래스 안에 메서드를 작성하는 형태로 시작합니다. 아래 코드를 `Hello.java`로 저장하면 기본적인 실행 예제를 만들 수 있습니다.

## 최소 실행 예제

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

## 코드 읽기

- `public class Hello`는 `Hello`라는 클래스를 선언합니다.
- `main`은 자바 프로그램을 실행할 때 사용하는 표준 진입 메서드입니다.
- `System.out.println(...)`은 괄호 안의 값을 출력하고 줄을 바꿉니다.
- 중괄호(`{ }`)는 클래스와 메서드의 시작과 끝을 나타냅니다. 실행할 문장은 메서드 중괄호 안에 작성합니다.
- 대부분의 자바 문장은 세미콜론(`;`)으로 끝납니다.

## `main` 메서드의 구성

```java
public static void main(String[] args)
```

- `public`: 실행 환경에서 메서드를 호출할 수 있도록 공개합니다.
- `static`: 객체를 만들지 않고 클래스에 속한 메서드로 호출할 수 있게 합니다.
- `void`: 메서드가 값을 반환하지 않는다는 뜻입니다.
- `String[] args`: 프로그램을 실행할 때 전달한 문자열 인수를 담습니다. 이 예제에서는 사용하지 않지만 기본 형태에 포함되어 있습니다.

## 클래스와 파일 이름

- 공개 최상위 클래스가 있는 일반적인 `.java` 파일은 파일 이름과 클래스 이름을 일치시킵니다. 따라서 `public class Hello`는 `Hello.java`에 작성합니다.
- 공개가 아닌 최상위 클래스는 같은 파일에 함께 선언할 수 있습니다.
- 클래스 이름은 대문자로 시작하는 `HelloWorld` 같은 표기법을 주로 사용합니다.

## 접근 제어자

접근 제어자는 클래스, 메서드, 필드에 다른 코드가 접근할 수 있는 범위를 정합니다.

| 제어자 | 접근 범위 |
| --- | --- |
| `public` | 어디서든 접근할 수 있습니다. |
| `protected` | 같은 패키지에서 접근할 수 있습니다. 다른 패키지에서는 상속 관계의 코드가 정해진 규칙에 따라 접근할 수 있습니다. |
| 생략 (`package-private`) | 같은 패키지 안에서 접근할 수 있습니다. |
| `private` | 선언된 클래스 안에서만 접근할 수 있습니다. |

최상위 클래스에는 `public` 또는 접근 제어자 생략을 사용할 수 있습니다. `protected`와 `private`는 최상위 클래스에 사용할 수 없습니다. 처음에는 `public`과 `private`를 익히고, 패키지와 상속을 배운 뒤 나머지 범위를 살펴보면 됩니다.

## 정리

- 자바 메서드는 클래스 안에 작성합니다.
- 표준 실행 예제는 `public static void main(String[] args)` 메서드에서 시작합니다.
- 공개 최상위 클래스가 있다면 파일 이름을 그 클래스 이름과 맞춥니다.
