# 자바 파일과 프로그램의 기본 구조

자바에서는 클래스 안에 메서드를 작성합니다. 아래는 `Hello.java` 파일에 들어가는 가장 간단한 실행 예제입니다.

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

## 코드 읽기

- `public class Hello`는 `Hello`라는 클래스를 선언합니다. `public` 클래스가 있으면 파일 이름은 클래스 이름과 같아야 하므로 파일 이름은 `Hello.java`여야 합니다.
- `main`은 표준적인 자바 프로그램의 시작 메서드입니다. JVM은 이 메서드에서 프로그램 실행을 시작합니다.
- `System.out.println(...)`은 괄호 안의 내용을 출력하고 줄을 바꿉니다.
- `{ }`는 클래스와 메서드의 범위를 나타냅니다. 메서드 안에 실행할 문장을 작성합니다.
- 문장의 끝에는 세미콜론(`;`)을 붙입니다.

## `main` 메서드의 구성

```java
public static void main(String[] args)
```

- `public`: JVM이 메서드를 호출할 수 있도록 공개합니다.
- `static`: 객체를 만들지 않고 클래스에서 바로 호출할 수 있게 합니다.
- `void`: 메서드가 값을 돌려주지 않는다는 뜻입니다.
- `String[] args`: 실행할 때 전달된 문자열 인수를 담습니다. 아직 사용하지 않아도 기본 형태에 포함해 둡니다.

## 클래스와 파일 이름

- 자바 메서드는 클래스 안에 선언합니다. 한 파일에 여러 클래스를 선언할 수 있지만, 공개(`public`) 최상위 클래스는 보통 파일 하나에 하나만 두며 파일 이름과 클래스 이름을 일치시킵니다.
- 예를 들어 `public class Hello`는 `Hello.java`에 작성합니다.
- 클래스 이름은 대문자로 시작하는 `HelloWorld` 같은 표기법을 주로 사용합니다.

## 접근 제어자

접근 제어자는 클래스, 메서드, 필드에 다른 코드가 접근할 수 있는 범위를 정합니다.

| 제어자 | 접근 범위 |
| --- | --- |
| `public` | 어디서든 접근할 수 있습니다. |
| `protected` | 같은 패키지에서는 접근할 수 있고, 다른 패키지에서는 상속 관계에서 접근할 수 있습니다. |
| 생략 (package-private) | 같은 패키지 안에서 접근할 수 있습니다. |
| `private` | 선언된 클래스 안에서만 접근할 수 있습니다. |

처음에는 `public`과 `private`부터 익히고, 패키지와 상속을 배운 뒤 나머지 범위를 자세히 살펴보면 됩니다.
