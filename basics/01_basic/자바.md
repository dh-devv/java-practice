# 자바란?

자바(Java)는 다양한 종류의 프로그램을 만들 때 사용하는 범용 프로그래밍 언어입니다. 웹 서비스의 백엔드와 기업용 시스템을 비롯해 여러 분야에서 사용되며, 표준 라이브러리와 다양한 개발 도구를 제공합니다.

## 자바 프로그램의 실행 과정

```text
Hello.java 소스 코드
        ↓ javac 컴파일러
Hello.class 바이트코드
        ↓ 운영체제에 맞는 JVM
프로그램 실행
```

`.java` 파일은 사람이 작성하는 소스 코드입니다. JDK에 포함된 `javac`가 소스 코드를 바이트코드가 담긴 `.class` 파일로 컴파일하고, JVM(Java Virtual Machine)이 바이트코드를 실행합니다. 각 운영체제에 맞는 JVM이 있기 때문에 같은 바이트코드를 여러 환경에서 실행할 수 있지만, 실제 실행에는 호환되는 JVM이 필요합니다.

## 주요 특징

- **객체 지향**: 프로그램을 클래스와 객체를 중심으로 구성합니다.
- **플랫폼 독립성**: 소스 코드를 바이트코드로 컴파일하고 JVM에서 실행하므로, 호환되는 JVM이 있는 환경에서 같은 바이트코드를 사용할 수 있습니다.
- **정적 타입**: 변수의 자료형을 선언하거나 추론해 사용합니다. 컴파일 과정에서 자료형과 관련된 오류를 찾는 데 도움이 됩니다.
- **자동 메모리 관리**: 가비지 컬렉터가 더 이상 사용되지 않는 객체의 메모리를 회수합니다.
- **라이브러리 활용**: 자바 표준 라이브러리와 외부 라이브러리를 이용해 다양한 기능을 구현할 수 있습니다.

## 활용 분야

- 웹 서비스와 서버 백엔드
- Android 앱 개발
- 데이터베이스를 사용하는 프로그램
- 빅데이터 및 분산 처리 시스템
- 게임 개발

iOS 앱 자체를 개발할 때는 주로 Swift를 사용하지만, 자바는 iOS 앱과 연결되는 서버를 만드는 데 사용할 수 있습니다. 어떤 언어를 선택할지는 프로젝트의 요구 사항과 개발 환경에 따라 달라집니다.

## JDK와 개발 환경

- **JDK(Java Development Kit)**: 자바 프로그램을 개발하는 도구 모음입니다. `javac` 같은 개발 도구와 프로그램 실행에 필요한 구성 요소를 제공합니다.
- **JVM(Java Virtual Machine)**: 컴파일된 자바 바이트코드를 실행하는 가상 머신입니다.
- **IDE(통합 개발 환경)**: 코드 작성, 실행, 디버깅을 돕는 도구입니다. IntelliJ IDEA와 Visual Studio Code 등이 있으며, 이 저장소의 예제는 Visual Studio Code에서 작성하고 실행합니다.

## 정리

- 자바 소스 코드는 컴파일되어 바이트코드가 되고, JVM이 이를 실행합니다.
- JVM이 제공되는 환경에서는 같은 바이트코드를 여러 운영체제에서 실행할 수 있습니다.
- JDK는 개발 도구를 제공하고, JVM은 바이트코드를 실행합니다.
