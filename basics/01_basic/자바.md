# 자바란?

자바(Java)는 여러 종류의 프로그램을 만들 때 사용하는 범용 프로그래밍 언어입니다. 특히 웹 서비스의 백엔드와 기업용 시스템에서 널리 쓰이며, 다양한 라이브러리와 개발 도구를 사용할 수 있습니다.

## 주요 특징

- **객체 지향 언어**: 프로그램을 클래스와 객체를 중심으로 구성합니다. 처음에는 클래스와 객체의 관계를 익히는 데 시간이 필요할 수 있습니다.
- **플랫폼 독립성**: 자바 코드를 바이트코드로 컴파일하고, 운영체제에 맞는 JVM(Java Virtual Machine)이 이를 실행합니다. 따라서 같은 바이트코드를 여러 환경에서 실행할 수 있습니다.
- **정적 타입 언어**: 변수와 값의 자료형을 코드에 명시합니다. 컴파일 과정에서 자료형과 관련된 오류를 일찍 발견하는 데 도움이 됩니다.
- **자동 메모리 관리**: 더 이상 사용되지 않는 객체의 메모리는 가비지 컬렉터가 회수합니다.
- **풍부한 라이브러리**: 자바 표준 라이브러리와 다양한 외부 라이브러리를 활용할 수 있습니다.

## 자바를 활용하는 분야

- 웹 서비스와 서버 백엔드
- Android 앱 개발
- 게임 개발
- 데이터베이스를 사용하는 프로그램
- 빅데이터 및 분산 처리 시스템

시스템 프로그래밍이나 하드웨어를 직접 다루는 작업에서는 보통 다른 언어가 더 많이 선택됩니다. 자바도 성능이 중요한 서비스에서 사용되지만, 프로젝트의 성능 요구와 개발 환경에 따라 언어를 선택합니다. iOS 앱의 기본 개발에는 주로 Swift가 쓰이며, 자바는 iOS 앱 자체보다 앱과 연결되는 서버 개발에 활용할 수 있습니다.

## 자바 프로그램의 실행 과정

```text
Hello.java 소스 코드
        ↓ javac 컴파일러
Hello.class 바이트코드
        ↓ JVM
프로그램 실행
```

`.java` 파일은 사람이 작성하는 소스 코드입니다. JDK에 포함된 `javac`가 이를 바이트코드가 담긴 `.class` 파일로 컴파일하고, JVM이 바이트코드를 실행합니다.

### JDK와 JVM

- **JDK(Java Development Kit)**: 자바 프로그램을 개발하는 도구 모음입니다. 컴파일러와 실행에 필요한 구성 요소가 포함되어 있습니다.
- **JVM(Java Virtual Machine)**: 컴파일된 자바 바이트코드를 읽어 실행하는 가상 머신입니다.

## IDE

IDE는 코드 작성과 실행을 돕는 개발 환경입니다. IntelliJ IDEA와 Visual Studio Code 등이 있으며, 이 저장소의 예제는 Visual Studio Code에서 작성하고 실행합니다.
