# 자료형과 연산자

자료형은 변수에 저장할 수 있는 값의 종류를 정하고, 연산자는 값이나 변수에 계산을 수행합니다.

## 기본 자료형

### 정수형

정수형은 소수점이 없는 수를 저장합니다. `int`를 가장 자주 사용하고, 더 큰 범위의 정수가 필요하면 `long`을 사용합니다.

| 자료형 | 설명 |
| --- | --- |
| `int` | 일반적으로 사용하는 정수형 |
| `long` | `int`보다 큰 범위의 정수를 저장할 때 사용 |

`long` 리터럴에는 숫자 뒤에 `L`을 붙입니다. 대문자 `L`은 숫자 `1`과 혼동하기 어려워 권장됩니다.

```java
int age = 20;
long population = 8_000_000_000L;
```

### 실수형

실수형은 소수점이 있는 수를 저장합니다. 소수 리터럴의 기본 자료형은 `double`이므로 `float` 값에는 `f`를 붙입니다.

| 자료형 | 설명 |
| --- | --- |
| `float` | `double`보다 정밀도가 낮은 실수형 |
| `double` | `float`보다 정밀도가 높은 실수형이자 소수 리터럴의 기본 자료형 |

```java
float height = 172.5f;
double pi = 3.14159;
```

실수형은 값을 근사하여 저장하므로 소수 계산 결과가 예상한 십진수와 정확히 일치하지 않을 수 있습니다.

### 문자형

`char`는 문자 하나를 저장합니다. 문자 리터럴은 작은따옴표로 감쌉니다.

```java
char grade = 'A';
```

### 논리형

`boolean`은 참 또는 거짓을 나타내며, 값은 `true`와 `false` 두 가지입니다.

```java
boolean isReady = true;
```

## 참조형: 문자열

`String`은 여러 문자를 이어 만든 문자열을 저장합니다. 기본 자료형이 아닌 참조형이며, 문자열 리터럴은 큰따옴표로 감쌉니다.

```java
String greeting = "안녕하세요";
```

## 숫자 연산자

| 연산자 | 의미 | 예시 |
| --- | --- | --- |
| `+` | 더하기 | `3 + 2` → `5` |
| `-` | 빼기 | `3 - 2` → `1` |
| `*` | 곱하기 | `3 * 2` → `6` |
| `/` | 나누기 | `5 / 2` → `2` (정수끼리 계산할 때) |
| `%` | 나머지 | `5 % 2` → `1` |

정수끼리 `/` 연산을 하면 나머지 부분은 버리고 0에 가까운 정수로 계산합니다. 소수 결과가 필요하면 적어도 한쪽 값을 실수형으로 계산합니다.

```java
int quotient = 5 / 2;              // 2
double decimalQuotient = 5.0 / 2;  // 2.5
```

## 증가 연산자

`++`는 변수의 값을 1 증가시킵니다. 변수 앞에 쓰는지 뒤에 쓰는지에 따라 식의 결과를 만드는 순서가 달라집니다.

| 형태 | 동작 |
| --- | --- |
| `++i` | 먼저 1 증가한 뒤, 증가한 값을 식의 결과로 사용합니다. |
| `i++` | 현재 값을 식의 결과로 사용한 뒤, 1 증가시킵니다. |

```java
int i = 3;
int prefix = ++i;  // i는 4, prefix도 4
int postfix = i++; // postfix는 4, 연산 후 i는 5
```

## 정리

- 정수는 `int`와 `long`, 실수는 `float`와 `double`을 주로 사용합니다.
- `String`은 문자열을 나타내는 참조형이고, `char`는 문자 하나를 나타내는 기본 자료형입니다.
- 정수끼리 나눈 결과는 정수이며, 실수 계산은 근삿값이 될 수 있습니다.
- `++i`와 `i++`는 증가 시점과 식의 결과가 다릅니다.
