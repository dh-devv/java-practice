# 자료형과 연산자

## 자료형

자료형은 변수에 저장할 수 있는 값의 종류를 나타냅니다.

### 정수형

소수점이 없는 정수를 저장합니다.

| 자료형 | 설명 |
| --- | --- |
| `int` | 일반적으로 사용하는 정수형 |
| `long` | `int`보다 큰 범위의 정수를 저장할 때 사용 |

자바에는 `byte`와 `short`도 있지만, 여기서는 자주 사용하는 `int`와 `long`을 중심으로 정리합니다.

`long` 값이 `int`의 범위를 넘을 때는 숫자 뒤에 `L`을 붙입니다.

```java
int age = 20;
long population = 8_000_000_000L;
```

### 실수형

소수점이 있는 수를 저장합니다.

| 자료형 | 설명 |
| --- | --- |
| `float` | 비교적 작은 정밀도의 실수형. 값 뒤에 `f`를 붙입니다. |
| `double` | 더 높은 정밀도의 실수형. 소수 리터럴의 기본 자료형입니다. |

```java
float height = 172.5f;
double pi = 3.14159;
```

### 문자형

`char`는 문자 하나를 저장하며, 작은따옴표로 값을 표현합니다.

```java
char grade = 'A';
```

### 문자열

`String`은 여러 문자를 이어 만든 문자열을 저장합니다. 기본 자료형이 아닌 참조형이며, 큰따옴표로 값을 표현합니다.

```java
String greeting = "안녕하세요";
```

### 불 자료형

`boolean`은 참 또는 거짓을 나타냅니다. 값은 `true`와 `false` 두 가지입니다.

```java
boolean isReady = true;
```

## 연산자

### 숫자 연산

| 연산자 | 의미 | 예시 |
| --- | --- | --- |
| `+` | 더하기 | `3 + 2` → `5` |
| `-` | 빼기 | `3 - 2` → `1` |
| `*` | 곱하기 | `3 * 2` → `6` |
| `/` | 나누기 | `5 / 2` → `2` (정수끼리 계산할 때) |
| `%` | 나머지 | `5 % 2` → `1` |

정수끼리 `/` 연산을 하면 소수 부분은 버립니다. 소수 결과가 필요하면 한쪽 값을 실수형으로 계산합니다.

```java
int quotient = 5 / 2;             // 2
double decimalQuotient = 5.0 / 2; // 2.5
```

### 증가 연산

`++`는 변수의 값을 1 증가시킵니다. 연산자를 변수 앞에 쓰는지 뒤에 쓰는지에 따라 식의 값이 달라집니다.

| 형태 | 동작 |
| --- | --- |
| `++i` | 먼저 1 증가한 뒤, 증가한 값을 식의 결과로 사용합니다. |
| `i++` | 현재 값을 식의 결과로 사용한 뒤, 1 증가시킵니다. |

```java
int i = 3;
int prefix = ++i;  // i는 4, prefix도 4
int postfix = i++; // postfix는 4, 연산 후 i는 5
```
