# ArrayList를 문자열로 변환하는 예제

`ArrayListToStringExample.java`는 배열의 값을 `ArrayList`로 만들고, 리스트를 문자열로 바꾸는 두 가지 방법을 보여줍니다.

## 사용한 메서드

| 메서드 | 설명 |
| --- | --- |
| `main(String[] args)` | 자바 프로그램이 시작되는 메서드입니다. |
| `Arrays.asList(data)` | 배열의 값을 담은 리스트를 만듭니다. |
| `size()` | 리스트에 들어 있는 요소의 개수를 반환합니다. |
| `String.join(", ", list)` | 리스트의 문자열 요소를 `", "`로 구분해 하나의 문자열로 합칩니다. |
| `get(index)` | 리스트에서 지정한 위치의 요소를 가져옵니다. 인덱스는 0부터 시작합니다. |
| `length()` | 문자열의 길이를 반환합니다. |
| `substring(begin, end)` | `begin`부터 `end` 직전까지의 부분 문자열을 반환합니다. |

`new ArrayList<>(...)`는 리스트를 만드는 생성자입니다. `System.out.println(...)`은 값을 출력하는 메서드입니다.

## 두 가지 문자열 변환 방법

- `String.join(", ", list)`는 구분자를 포함해 요소를 간단히 합칩니다.
- 반복문을 사용하는 방법은 각 요소 뒤에 `", "`를 붙인 뒤, 마지막 구분자를 `substring()`으로 제거합니다. 리스트가 비어 있지 않을 때만 제거해야 하므로 `length()`를 확인합니다.

리스트를 문자열로 합치는 일반적인 경우에는 `String.join()`이 더 간결합니다.
